# Cache strategy simulator

Небольшой симулятор одноуровневых и многоуровневых кешей. Симулятор хранит
только целочисленные ключи и считает попадания и промахи; значения страниц ему
не нужны.

Поддерживаемые политики: `LRU`, `LFU`, `2Q`, `ARC`, `LIRS`, `OPT`.

## Сборка

Требуются CMake 3.11 или новее и компилятор с поддержкой C++17.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

Конфигурация по умолчанию копируется в каталог сборки, поэтому программу можно
запускать как из корня проекта, так и из `build/`.

## Вход и выход

На stdin передаются ёмкость каждого уровня, количество запросов и ровно столько
целочисленных ключей:

```text
cache_capacity request_count key...
```

Пример:

```sh
printf '2 6 1 2 1 2 1 2\n' | ./build/cache
```

Программа выводит только число попаданий:

```text
4
```

Путь к другому конфигу можно передать первым аргументом:

```sh
./build/cache path/to/config.txt
```

## Конфигурация

Сначала указываются количество уровней и политика каждого уровня — от самого
быстрого к самому медленному:

```text
2 LRU ARC
```

Все уровни имеют ёмкость `cache_capacity`, прочитанную из stdin. Иерархия
эксклюзивная: ключ находится только на одном уровне; при попадании на нижнем
уровне он поднимается на первый, а вытесненные ключи последовательно переходят
ниже.

После политик можно указать необязательные стоимости попаданий на каждом уровне
и стоимость полного промаха:

```text
2 LRU ARC
costs 1 10
miss_cost 100
```

По умолчанию все стоимости равны `1`. 

`OPT` использует всю трассу запросов и предназначен как теоретическая нижняя
граница для сравнения остальных политик.
